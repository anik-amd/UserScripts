# UserScripts

Personal collection of browser userscripts. Each script includes a `@match`/`@include` header and can be installed via a userscript manager such as Tampermonkey or Violentmonkey.

## Scripts

| Script | What it does |
| --- | --- |
| [`qwen-enter-to-send.user.js`](scripts/qwen-enter-to-send.user.js) | Sends the Qwen Chat message on **Enter**. `Shift+Enter` / `Alt+Enter` still inserts a newline; IME composition and mention popups are left alone. |

## Layout

```
scripts/<name>.user.js
```
